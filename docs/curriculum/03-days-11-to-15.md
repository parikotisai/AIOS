# Days 11–15 — Finish Loops, Start Function Calls

**Where you stand:** your evaluator handles assignment, arithmetic, strings/lists/dicts/indexing, and if/else with comparison and boolean operators, and can run a while loop once.

---

### Days 11–12 — Finish while loops
- Get multi-iteration loops fully correct — each pass through the loop should show up as its own step(s), with the loop condition re-checked each time.
- **Done when:** a loop that runs 5 times produces a trace with visibly repeating line numbers, and stops at the right point.

### Days 13–15 — Function calls + call stack (start)
This is the hardest part of Phase 1 — give it the full 3 days.
- Track a stack of "frames." Each function call pushes a new frame onto the stack with its own local variables. Returning pops that frame off.
- Start with a simple, non-recursive function first (e.g. `def add(a, b): return a + b`) before attempting recursion.
- **Done when:** a call to a simple one-line function produces a correct trace showing a frame pushed and popped, with the right local variables inside it.
