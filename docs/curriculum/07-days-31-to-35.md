# Days 31–35 — First AI API Call

**Where you stand:** Phase 2 is complete. Your tracer and UI are tested, and the tests run automatically on every push.

---

### Days 31–33 — First real API call
- Take one step's data (line + variables) from your trace and send it to an LLM API, asking for a one-sentence plain-English explanation.
- **Done when:** you can print a correct, sensible AI-generated sentence describing a real step your own tracer produced.

### Days 34–35 — Start wiring it into the app
- Add an "Explain this step" button next to your step controls.
- Wire the button to send the current step's data and display the AI's response.
- **Done when:** clicking the button on at least one step shows a real explanation in the UI (doesn't need to be polished yet).
