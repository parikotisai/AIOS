# Days 21–25 — First Playwright Tests

**Where you stand:** Phase 1 is complete. You have a working full-stack code visualizer, built entirely by you.

---

### Days 21–22 — First test
- Install Playwright.
- Write a test that opens your app and checks the page loaded (e.g. checks for a known element or title).
- **Done when:** `npx playwright test` runs and passes.

### Days 23–24 — UI-level test, structured as a Page Object
- Before writing the test itself, write a `CodeVisualizerPage` class that wraps your app's selectors and actions (`enterCode()`, `clickRun()`, `getTracePanelText()`) — this is the Page Object Model: tests call the page object's methods, never raw selectors directly. When your UI changes later, you fix one class instead of every test that touches that element.
- Write the test using only that page object: types code into the editor, clicks Run, checks that the trace/variables panel is no longer empty.
- **Done when:** this test fails if you deliberately break the Run button, and passes when it's fixed — **and** your test file itself contains no raw CSS/text selectors, only calls to the page object.

### Day 25 — Start a correctness test
- Begin a test that runs a known program through the UI (e.g. `x = 5\ny = x + 3`) and checks the displayed result.
- **Done when:** you can assert on at least one specific value shown on screen after Run.
