# Session Notes

One file per curriculum day: `day-NN.md` (e.g. `day-01.md`).

Each day's file automatically captures, as the session happens:

- **Objective** — the day's goal in one line, from the curriculum doc.
- **Concepts & definitions** — every new term explained that day, with
  the analogy used. No minute detail skipped.
- **Q&A log** — every question asked and the answer given.
- **What we built / ran** — commands run, files created, results,
  errors hit and how they were debugged.
- **Diagrams** — Mermaid diagrams for anything architectural or flow-based
  (render in VS Code markdown preview and on GitHub).
- **Check-your-understanding** — the self-test questions and my answers.
- **Wrap-up** — summary, homework, commit message, prep for tomorrow.

These notes are maintained by Claude automatically during sessions
(see CLAUDE.md → Session Notes). They are a learning journal, not
source of truth — the curriculum docs in `docs/curriculum/` own the plan.
